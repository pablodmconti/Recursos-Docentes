Momento 1 · 10 min

¿La computadora entiende esto?

Este es el pseudocódigo que escribimos para calcular el área de un rectángulo. Usa tres comandos: input recibe un dato, = guarda un valor y output muestra el resultado.

Pseudocódigo · área del rectánguloinput base input altura area = base * altura output area
¿Puede la computadora ejecutar esto tal cual?

No. El pseudocódigo está pensado para personas: no tiene reglas estrictas y cada uno lo escribe un poco distinto. La computadora necesita un lenguaje con reglas exactas que se pueda traducir a instrucciones para el procesador. Por eso hoy pasamos a Python.

¿Y los bloques de Code.org?

Los bloques también son una forma de programar, pero por detrás se convierten en código escrito. Hoy vamos a escribir ese código nosotros mismos.

Paso 2

Guardar datos en variables

Una variable es una caja con nombre donde se guarda un dato. El signo = guarda el valor de la derecha en la variable de la izquierda.

OjoLos nombres de variables van sin espacios ni tildes: area, no área. Para unir palabras se usa guion bajo: precio_total.

Paso 6

El programa completo

Ya tienen todas las piezas. Así queda el pseudocódigo del área traducido a Python, línea por línea:

PseudocódigoPython
input base
→
base = float(input("Base: "))
input altura
→
altura = float(input("Altura: "))
area = base * altura
→
area = base * altura
output area
→
print("El área es", area)

En Python los decimales se escriben con punto: 2.5, no 2,5.

Guía de errores frecuentes

NameError: name '___' is not defined
Todavía queda un espacio ___ sin completar.
NameError: name '…' is not defined
Python no conoce ese nombre. Revisen cómo está escrito, con mayúsculas incluidas, y que la variable tenga un valor antes de usarla.
TypeError: can't multiply sequence by non-int of type 'str'
Están multiplicando textos. Conviertan el dato de input() con float() o int().
ValueError: could not convert string to float
El dato no es un número. Si tiene decimales, escríbanlo con punto: 2.5.
SyntaxError
Hay un error de escritura en esa línea o en la anterior: un paréntesis o unas comillas sin cerrar, o espacios al comienzo de la línea.
